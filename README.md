## The entry

> My fitness tracker's Sleep Score dropped to 42 because I lay there staring at the ceiling for nine straight minutes.

A fitness tracker that grades your insomnia: lying awake counts against you, and the device keeps the score.

## How it works

`main.ts` writes the line above, byte-exact and with no trailing newline, to `/output/entry.txt`. It checks the entry first (1-200 characters, not blank). Run `bun main.ts --self-test` to write the file, read it back and confirm it is byte-identical.
